Status — never colour alone

✓ Saved to school ◍ On this phone ✕ Could not save ★ Grade A · Excellent ◷ Awaiting approval

Each state pairs a colour with a glyph and a word, so it survives greyscale printing and colour-vision differences (WCAG 1.4.1). Report cards get printed in black and white constantly — a grade that only reads as "green" would be lost.

Tabular figures keep scores and money in true columns — 9 and 100 line up, so an outlier is visible by shape before it is read. Identifiers use monospace because they get read aloud and checked against paper receipts, where a transposed digit is the common error.

Why it looks like this

  • Five states, one tap. Present, Absent, Late, Excused, Sick as a segmented control — not a dropdown, not a modal.
  • Every row states its own truth. "On this phone" and "saved to school" are different sentences. The interface always uses the true one.
  • The button never lies. Offline it reads "Submit when back online", because it will queue, not send.
  • 44px targets, 56px rows. One-handed use, standing up, in a room of children.

What is deliberately missing

  • No sidebar, no dashboard grid, no KPI cards.
  • No app install required — this is a link that opens.
  • No webfont. Body text uses the phone's own font, which costs nothing to download and renders instantly.
  • Body text never smaller than 16px. Guardians span every age and eyesight.

Same model, different input shape

  • A stepper, not a spreadsheet — correct for a thumb, not a mouse. The Staff Console keeps the desktop grid.
  • Tap the number to open the device's own numeric keypad for direct entry.
  • Bounds (0–100 here) are enforced the same way on both surfaces, server-side.
  • One SyncLedger, one vocabulary — a teacher learns "on this phone" vs "saved to school" once, not twice.
